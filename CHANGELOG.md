# Changelog — Daily Logistics One Page

Todas as alterações relevantes realizadas no projeto serão documentadas neste arquivo.

O objetivo é manter a rastreabilidade das evoluções, correções e melhorias implementadas na automação n8n.

---

## [1.0.0] — 12/11/2026

### Versão inicial — Produção

**Status:** Em produção

### Adicionado
- Publicação da versão inicial oficial do workflow Daily Logistics One Page.
- Estrutura de automação desenvolvida na plataforma n8n.
- Integração com SQL Server para consulta dos dados operacionais.
- Consultas SQL utilizadas na consolidação dos indicadores.
- Estrutura de apresentação e visualização em HTML.
- Documentação dos indicadores logísticos.
- Organização do repositório GitHub.

### Organização do projeto
- `workflows/`: workflow oficial de produção.
- `workflows/archive/`: versões anteriores utilizadas durante o desenvolvimento.
- `sql/`: consultas SQL do projeto.
- `docs/`: documentação técnica e funcional.
- `preview/`: arquivos de pré-visualização do layout.

### Observações
- A versão 1.0.0 representa o primeiro registro oficial do projeto no GitHub.
- As versões anteriores do workflow foram preservadas para consulta.
- Novas alterações serão registradas neste documento.
